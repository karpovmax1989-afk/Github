# Golden Key — сайт агентства недвижимости

Многостраничный сайт агентства недвижимости **Golden Key**.

## Страницы

| Файл | Раздел |
|------|--------|
| `index.html` | Главная — hero, поиск, статистика, объекты, отзывы |
| `about.html` | О компании — история, миссия, достижения |
| `catalog.html` | Каталог недвижимости с фильтрами |
| `services.html` | Услуги — покупка, продажа, аренда, ипотека |
| `cases.html` | Кейсы — успешные сделки с результатами |
| `reviews.html` | Отзывы — рейтинг и отзывы клиентов |
| `team.html` | Команда — карточки экспертов |
| `contacts.html` | Контакты — форма связи, карта |

## Файлы

- `styles.css` — общая дизайн-система (золото-синяя тема, светлая/тёмная)
- `main.js` — переключение темы, мобильное меню, анимации, формы

## Особенности

- 📱 Полностью адаптивный дизайн (мобильный, планшет, десктоп)
- 🌗 Светлая и тёмная темы (сохраняется в localStorage)
- ♿ Доступность (семантика, aria-метки, focus-стили)
- 🎨 Единый фирменный стиль Golden Key
- ⚡ Без внешних зависимостей — чистые HTML/CSS/JS

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Данные

Контент (адреса, телефоны, объекты, фото) — демонстрационный.
Изображения — SVG-плейсхолдеры, которые можно заменить на реальные фото.
